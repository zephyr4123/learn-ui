# learn-ui

给研发的 UI 课，从零开始，纯讲解。先认识界面由哪些零件组成，再逐个讲清每种零件的规律，最后串起来，学会看懂一个界面好在哪、差在哪。

## 打开方式

```bash
open index.html        # 课程目录
```

纯静态 HTML，不需要安装任何东西，所有文件都在本地。

## 目录

```
index.html                 课程目录
checklist.md               每课要点速查（学完一课多一节）
assets/
  lesson.css               课程页面公共样式（手机/浏览器外框、标注、度量表）
  lesson.js                眯眼测试、标注、度量等演示功能
lessons/NN-主题/index.html  每一课
```

## 依据

以官方规范为准：Apple HIG、Material Design 3、WCAG 2.2。WCAG 3.0 和新的对比度算法 APCA 截至 2026 年仍是草案，只作参考。经验类规则主要来自 Refactoring UI 和 NN/g，课里会标明哪些是硬标准、哪些是经验值。
