用户长期做研发，不是 UI/设计出身。在 learn-ui 项目里想学两件事：① 通用 UI 规范；② 面对一个界面能判断好坏、说清好在哪/差在哪、怎么改。特别想知道"美"怎么定义、怎么度量，反感空泛的审美说法。日常手机和网页都做，iOS 做得最多。

**How to apply:** 示例以 iOS 为主、网页穿插。讲解尽量落到可度量的数值和规则（对比度、间距网格、字号层级、触控尺寸等），用"坏版 vs 好版"的 HTML 对照教学；可以用工程类比（tokens≈变量、lint≈规范检查）。不用讲太细太碎。
